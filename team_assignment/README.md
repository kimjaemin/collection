# 그룹과제 팀 편성 프로그램

수강생 39명 + 청강생 2명(총 41명)을 A, B, C, D 4개 팀으로 랜덤 배치합니다.

## 배치 방식
1. 학생 이름을 한 번에 **4~5명씩** 입력합니다. (한 줄 = 한 번의 추첨)
2. 4명인 줄은 A, B, C, D팀에 **한 명씩 랜덤으로** 배치됩니다.
3. 5명인 줄은 네 팀에 한 명씩 들어가고, 남은 한 명은 **11명이 될 팀**에 들어갑니다.
   (예: 4명 9줄 + 5명 1줄 = 41명)

결과: 10명 팀 3개 + 11명 팀 1개

### 팀 고정
특정 학생을 원하는 팀에 미리 고정할 수 있습니다. 고정된 학생은 자기 차례에 정해 둔 팀으로 들어가고,
같은 4명 묶음의 나머지 학생은 남은 팀으로 랜덤 배치됩니다. 팀 인원(10명/11명)은 항상 지켜집니다.

## 화면으로 추첨하기 (`index.html`)
수업 시간에 화면에 띄워 놓고 학생들과 함께 보면서 추첨하는 버전입니다.
브라우저로 `index.html` 파일을 열면 바로 사용할 수 있습니다.

1. 명단 칸에 학생 이름을 한 줄에 4~5명씩 입력합니다. (입력한 내용은 브라우저에 저장됩니다)
2. 필요하면 **팀 고정**에서 학생과 팀을 골라 고정합니다.
3. **추첨 시작** → **다음 N명 뽑기**(또는 스페이스바)를 누를 때마다 한 줄의 팀이 하나씩 공개됩니다.
4. 추첨이 끝나면 11명 팀이 공개되고, **결과 복사**로 팀 명단을 복사할 수 있습니다.
5. **같은 명단으로 다시 추첨**을 누르면 명단과 팀 고정 설정은 그대로 둔 채 처음부터 다시 추첨합니다.

## 터미널에서 실행하기 (`team_assign.py`, Python 3, 추가 설치 불필요)
```bash
# 1) 4~5명씩 직접 입력 (쉼표로 구분)
python3 team_assign.py
# [1번째 입력] 4~5명 (0/41): 김철수, 이영희, 박민수, 최지우
# ...
# [10번째 입력] 4~5명 (36/41): 가, 나, 다, 라, 마

# 2) 파일에서 이름 읽기 (한 줄에 4~5명 쉼표 구분, 또는 한 줄에 한 명씩 → 4명씩 묶음)
python3 team_assign.py sample_names.txt

# 3) 같은 결과를 다시 보고 싶을 때 시드 지정
python3 team_assign.py sample_names.txt --seed 42

# 4) 특정 학생을 팀에 고정 (여러 번 사용 가능)
python3 team_assign.py sample_names.txt --fix 김제민=A --fix 학생05=C
```
직접 입력 방식에서는 이름을 모두 입력한 뒤 고정할 학생을 물어봅니다. (`김제민=A` 형식, 없으면 엔터)
