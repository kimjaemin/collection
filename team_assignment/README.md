# 그룹과제 팀 편성 프로그램

수강생 39명 + 청강생 2명(총 41명)을 A, B, C, D 4개 팀으로 랜덤 배치합니다.

## 배치 방식
1. 학생 이름을 **4명씩** 입력합니다.
2. 입력된 4명은 A, B, C, D팀에 **한 명씩 랜덤으로** 배치됩니다. (10번 반복 → 각 팀 10명)
3. 마지막으로 남은 1명은 랜덤한 팀에 배치되어 그 팀은 **11명**이 됩니다.

결과: 10명 팀 3개 + 11명 팀 1개

## 실행 방법 (Python 3, 추가 설치 불필요)
```bash
# 1) 4명씩 직접 입력 (쉼표로 구분)
python3 team_assign.py
# [1번째 입력] 4명 (0/41): 김철수, 이영희, 박민수, 최지우
# ...
# [11번째 입력] 1명 (40/41): 홍길동

# 2) 파일에서 이름 읽기 (한 줄에 한 명 또는 쉼표 구분)
python3 team_assign.py sample_names.txt

# 3) 같은 결과를 다시 보고 싶을 때 시드 지정
python3 team_assign.py sample_names.txt --seed 42
```
